# Hackedbox Styles

A community repository for styles and themes for [Hackedbox](https://github.com/Blame582/hackedbox).

## About

This repository serves as a central collection of styles for Hackedbox. It brings together styles created by the community, making it easier for users to discover, share, and use different looks for their desktop.

## Contribute a Style

**Have a Hackedbox style you'd like to share? Contributions are welcome!**

Users are encouraged to submit their own styles for inclusion in this repository. Whether you've created something new or customized an existing style, consider sharing it with the community.

To submit a style:

1. Fork this repository.
2. Add your style in its own directory, including the files required for it to work.
3. Open a pull request describing your style and any relevant requirements.

Styles should be tested with Hackedbox before submission and should include any assets they need to function.

## Browse Styles

Explore the directories in this repository to find available styles. Each style may include its own configuration files, wallpapers, or other assets.
